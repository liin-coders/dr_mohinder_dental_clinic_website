# Dr. Mohinder Dental Clinic — Website Starter

## Run locally
Open `index.html` in a modern browser, or use VS Code Live Server.

## Files
- `index.html` — single-page website and all content sections
- `css/style.css` — responsive styling and clinic color palette
- `js/main.js` — navigation, sliders, galleries, lightbox and form validation
- `images/` — place clinic-provided assets here

## Important before publishing
1. Images currently use online sample photos for layout preview. Replace them with the clinic's actual, approved photographs. Clinical case galleries should only use the correct supplied images and captions.
2. Testimonials are clearly marked as placeholder copy. Replace them with genuine, clinic-approved patient feedback before publication.
3. The contact form opens WhatsApp with a prefilled enquiry; the visitor must press Send in WhatsApp. It does not silently send a message or email the clinic.
4. Confirm the clinic's exact Google Maps pin and current timings before going live.
5. Review the credentials, contact details, domain setup, privacy requirements and SEO metadata with the clinic before launch.
6. The page is a single-page starter. Navigation items jump to sections; separate URLs/pages can be added if required.

## Image replacement
Replace each sample image URL in `index.html` with a local path such as `images/hero/slide-1.jpg`. Keep meaningful `alt` text for accessibility.
